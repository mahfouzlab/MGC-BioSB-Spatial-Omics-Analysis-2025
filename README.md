# MGC-BioSB-Spatial-Omics-Analysis-2025

This 4-day intensive course provides hands-on training in spatial omics data analysis, focusing on spatially-resolved transcriptomics (SRT). Participants will learn the complete analytical workflow from data preprocessing to advanced spatial analysis through a combination of lectures and practical sessions. The course covers both imaging-based and sequencing-based approaches, cell segmentation techniques, data integration, spatial domain identification, and cell-cell communication analysis.

### Learning Objectives
- Identify and recall key concepts and terminology related to imaging- and sequencing-based SRT technologies.
- Assess and evaluate quality of SRT data.
- Perform standard SRT data analysis, including data cleaning, normalization, quality control.
- Examine and interpret spatial patterns and relationships within SRT data using statistical and machine learning approaches.
- Construct a comprehensive workflow for SRT data analysis, from raw data to meaningful biological insights.

### Topics covered
- Overview of spatial transcriptomics technologies
- Cell segmentation
- Imaging-based spatial data preprocessing
- Segmentation-free analysis
- Sequence-based spatial data preprocessing
- Spatial data integration
- Graph representations/Niche reconstruction
- Spatial domain identification/spatial annotation
- Cell-cell communication
